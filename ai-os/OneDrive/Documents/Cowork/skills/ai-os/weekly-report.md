# Accomplishments and the weekly report

The flywheel: anything of substance gets logged on the Done sheet as it
happens, so the weekly report is mostly written by the time Friday comes.

## done: <accomplishment>

1. Rewrite it as an outcome in past tense if it isn't one ("met with MRM
   about validation" → ask "What came out of it?" or log "Agreed validation
   scope with MRM").
2. Work out the topic and the Jira key if there is one.
3. Append to Done: Date = today unless I said otherwise, Source = `Session`.
4. Reply in one line.

## draft weekly report

1. **Log.** Read Done rows where This week = Yes.
2. **Sweep.** Look through this week's sent email, Teams messages and
   calendar for substantive work that never got logged: deliverables sent,
   decisions I drove, meetings I ran. List them and ask which to add to
   Done. Add the ones I approve (Source = Email / Teams / Calendar) before
   writing.
3. **Inventory.** This week's rows: New, Know, Decisions opened, and
   Resolved.
4. **Jira.** From the Jira sheet: issues that changed stage this week (compare
   with last week's report if there is one in `Reports/`), issues needing
   attention, and the pipeline count by stage from the Dashboard.
5. **Write** it as a Word doc at `Drafts/Weekly-<Monday YYYY-MM-DD>.docx`
   in this structure:

   **Headline:** one sentence on the week.

   **What's new:** 3–5 bullets.

   **What we need to know:** risks and constraints, each with its INV ID.

   **Decisions needed:** open decisions, oldest first: the ask, who decides,
   by when, age.

   **Delivered this week:** accomplishments grouped by topic.

   **Portfolio:** stage counts, issues that moved, issues needing attention.

   **Next week:** the top three things I'm driving.

6. Run the Review Gate (`review-gate.md`) on the draft yourself and fix only
   what's mechanical (missing IDs, missing dates). Report anything else.
7. Tell me where the draft is. Don't send it. When I say it's final, move it
   to `Reports/` and log the move on the Changes sheet.

## Rules
- Every claim in the report traces to a Done row, an Inventory row, or a
  Jira key.
- Nothing from `Private/`.
- If a section has nothing in it, write "None this week." Don't pad.
