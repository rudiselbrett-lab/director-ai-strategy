    How to read this dashboard & process reference

    The lifecycle

    No initiative advances without satisfying the decision criteria for its current stage. Closed outcomes (Declined, Transferred) are portfolio data too — toggle “Show closed” above.

    Triage outcomes

    DecisionMeaning
    ApproveValue is credible; committing capacity now. Needs a named sponsor, no open risk flag, and an agreed value measure.
    Rapid PrototypeValue plausible but unproven — two weeks, capped, to buy evidence. Returns to triage once.
    More DiscoveryOne specific written question blocks the decision. One cycle; a second return forces Approve or Decline.
    PartnerThe capability belongs elsewhere. Warm handoff; closes as Transferred.
    DeclineNot proceeding — a normal outcome. Requester hears it directly, with the reason.
